Help with OG Files on macOS, Windows and Linux

Get help or report a problem

Open an issue at github.com/OmegaGiven/og-files/issues. Include your operating system and version, the OG Files version you installed and, if a particular file misbehaves, its type.

Common questions

  • Mac App Store version: a folder shows "needs your permission". Click Grant Access… and choose that folder, or your home folder to allow everything in it. OG Files remembers the choice.
  • Which videos play? The Mac App Store version plays what macOS plays natively: mp4, m4v and mov (H.264, HEVC, ProRes). The direct downloads bundle libmpv and play nearly everything, including mkv and webm.
  • Where are my settings? macOS: ~/Library/Application Support/og-files (inside the app's container for the App Store version). Windows: %APPDATA%\og-files. Linux: ~/.config/og-files.
  • Downloads for other systems: see the releases page.
